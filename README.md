# Runtime GPU Memory Model Adaptation
Looking into the tradeoffs of switching the CUDA memory model at runtime

## Requirements
Check with ``` make check```

## Root
local -> Local Python to run experiments
book -> Information, Documentation
remote -> Synced directory on the cluster

## Remote
remote/bin/sac2c -> link to sac2c compiler
remote/sac2c -> fork of the sac2c compiler
remote/stdlib -> fork of the sac2c stdlib

## Local
local/setup.py -> Run for setup of the environment
local/cli.py -> Run for easy interfacing with remote
